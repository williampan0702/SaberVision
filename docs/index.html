⚔ OFFLINE PROTOTYPE

SaberVision

A working sabre-refereeing prototype that combines fencer detection, detailed pose estimation, guard-to-tip direction, score-box lamps, and time-synchronized evidence.

This is an engineering prototype, not an officially certified competition referee. This page shows genuine offline results; full video inference runs in a local Python and FFmpeg environment.

24-second processed-results montage. Four real outputs show fencer detection, pose and weapon direction, score-box light tracking, and double-light priority review.

What the video shows

01 · DETECT

Locate both fencers

Person boxes keep later analysis focused on the athletes rather than the whole broadcast frame.

02 · TRACK

Follow motion over time

Pose keypoints and weapon-wrist direction are evaluated across consecutive frames, not from one still image.

03 · SYNCHRONIZE

Read the score-box lamps

Lamp events anchor the relevant time window and are kept separate from the priority decision.

04 · DECIDE

Award or request review

Double-light priority is automatic only when the synchronized motion evidence clears the safety rule.

Current prototype safeguards

1/1
One clear lamp source is enough

The system does not use confidence voting or an N-of-3 requirement.

100
Double-light engineering cases

A cross-venue safety set, including 19 no-award cases with zero incorrect automatic awards.

1.70
Automatic priority threshold

The 0.35 s and 0.75 s motion windows must cross the threshold in the same direction.

Run the system locally

GitHub Pages hosts this explanation and the processed demo video. Full inference runs offline because it requires Python, PyTorch, OpenCV, and FFmpeg.

python -m pip install -r requirements.txt
& ".\run_sabervision_mvp.ps1" -InputVideo "D:\path\exchange.mp4"

Outputs

Given one exchange clip, the pipeline produces an H.264 video with pose and decision overlays, a machine-readable verdict.json, and a review page with a 12-frame contact sheet and half-speed clip whenever human review is required.
